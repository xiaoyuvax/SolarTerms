# SolarTerms24Net

基于天文算法的**中国农历 / 二十四节气**推算库，C# / .NET 9 实现。

本项目移植自 Python 项目 [Comee/SolarTerms24](https://github.com/Comee/SolarTerms24)，常数表与算法步骤与原版逐行对应，计算结果精确到秒，无需依赖任何星历表文件或第三方天文库。

## 功能

- **二十四节气**：任意年份 24 节气的精确时刻（北京时间），精度与权威万年历一致
- **农历月序推排**：按「以中气定月序」规则排出全年农历月，标注大月（30 天）/ 小月（29 天）
- **闰月推算**：自动识别无中气之月并置闰，正确处理闰月导致的月序重排
- **朔日（新月）时刻**：基于月球运动级数理论计算日月合朔时刻

## 天文算法

| 模块 | 说明 |
|---|---|
| VSOP87 地球运动理论 | 计算太阳黄经 / 黄纬 / 地日距离（E10–E35 周期项级数） |
| 月球运动理论 | 计算月球黄经 / 黄纬 / 距离（M10–M31 级数） |
| 章动 (Nutation) | IAU 章动序列修正 |
| 岁差 (Precession) | 长期岁差修正 |
| 光行差 (Aberration) | 太阳光行差修正 |
| ΔT 修正 | 内置 -4000 ~ 2150 年 ΔT 多项式插值表，实现 TT ↔ UT 换算 |
| 求根 | 割线法迭代求解「太阳视黄经 = k·15°」（节气）与「日月黄经差 = 0」（朔日）的精确时刻 |

## 项目结构

```
SolarTerms24Net.sln
├── SolarTerms24Net/          # 核心类库
│   ├── SolarTerms.cs         # 天文算法 + 农历排月规则（入口：SolarTerms.PaiYue）
│   ├── JDate.cs              # 儒略日 / 公历互转 + ΔT 修正
│   ├── PaiYueItem.cs         # 排月结果数据结构
│   └── Utils.cs              # 配置读取辅助（Py2Cs 移植配套）
└── SolarTermsCmd/            # 控制台示例程序
    └── Program.cs            # 调用 PaiYue 并输出结果
```

## 快速开始

### 环境要求

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

### 运行示例

```bash
git clone https://github.com/<你的用户名>/SolarTerms24Net.git
cd SolarTerms24Net
dotnet run --project SolarTermsCmd -c Release
```

结果写入 `output/output.txt`，控制台输出 `==============finished!============`。

### 库调用

在你的项目中引用 `SolarTerms24Net` 类库后：

```csharp
using SolarTerms24Net;

// 传入年份字符串，返回全年农历排月 + 节气文本
string result = SolarTerms.PaiYue("2001");
Console.WriteLine(result);
```

## 设计说明

- **零依赖**：所有天文常数（VSOP87、章动表、ΔT 表）内嵌于源码，无需星历数据文件
- **忠实移植**：与 Python 原版一一对应，便于逐函数比对验证
- **库 / 壳分离**：`SolarTerms24Net` 为纯计算类库（唯一公开入口 `SolarTerms.PaiYue`），`SolarTermsCmd` 为薄壳入口，方便集成到其他项目
